# Мокап приложения «Тренировки»

Статичный HTML/CSS макет мобильного приложения для трекинга тренировок:
приседания · отжимания · подтягивания · брусья, с жилетом 0–30 кг на каждый подход.

## Как посмотреть

```bash
# Из корня репозитория
open mockup/index.html
# или
xdg-open mockup/index.html
```

Никакого сервера не нужно — всё работает из `file://`.

## Что внутри

```
mockup/
  index.html         — лендинг: все 5 экранов в «телефонах» рядом
  screens/
    home.html        — главная: старт тренировки, серия, статистика недели
    workout.html     — активная тренировка: выбор упражнения, подходы, жилет, таймер отдыха
    history.html     — история: список тренировок, группировка по месяцам
    progress.html    — прогресс: график + личные рекорды по упражнению
    detail.html      — деталь тренировки: подходы, заметки, действия
  assets/
    styles.css       — общий стиль, CSS-переменные, тёмная тема
    icons.svg        — SVG-спрайт (для справки)
    icons.js         — тот же спрайт, который инжектится в каждый экран
```

Каждый экран открывается и самостоятельно (`screens/home.html`), и в составе
галереи — внутри iframe `index.html`.

## Что это даёт

Цель мокапа — согласовать вид и поток экранов до того, как вкладываться в
сборку Tauri-приложения. Никакой логики внутри: кнопки и слайдеры не
реагируют на клики.
